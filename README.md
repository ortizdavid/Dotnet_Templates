# Dotnet Templates  

A collection of .NET project templates designed for efficiency, simplicity, and production readiness.  


## ✅ Benefits  
- **Production-Ready**  
- **Easy Configuration**  
- **Clean & Maintainable Code**  
- **Simplified Development**  


## 📦 Each Project Includes  
- [x] All Features  
- [x] Architecture Design  
- [x] Database Migrations  
- [x] Observability  
- [x] Structured Log Monitoring  
- [ ] Containerization (In Progress)  
- [ ] Tests  
- [ ] CI/CD Pipeline  


## 📌 Available Templates  
- [x] **REST API** – Full-featured RESTful API  
- [x] **Simple REST API** – Lightweight version of REST API  
- [x] **MVC App** – Model-View-Controller web application  
- [x] **Simple MVC App** – Basic MVC template for prototyping  
- [x] **Minimal API** – Lightweight API with minimal setup  
- [x] **RabbitMQ API** – Producer/Consumer API using RabbitMQ  
- [x] **NATS API** – Publisher/Subscriber API using NATS  
- [x] **Event-Driven** – Event-driven architecture template  
- [ ] **CQRS** – Command Query Responsibility Segregation 


## 🎯 Purpose  
These templates accelerate development by providing a solid foundation for different project types, from REST APIs to event-driven systems.
